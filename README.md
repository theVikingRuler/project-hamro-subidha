# Project Hamro Subidha

Developed at **Uunchai 2026**

Project Hamro Subidha is a student-led platform designed to bridge the accessibility gap in Nepal’s public welfare landscape by streamlining scattered scholarships, agricultural loans, municipal grants, and subsidies into a single, accessible directory. While hundreds of support programs exist, their details are currently fragmented across physical school notice boards, unindexed municipal websites, and word-of-mouth—disproportionately excluding non-urban and under-resourced communities. Built by a team of student researchers and engineers under mentor guidance, Hamro Subidha digitizes primary government notices and school circulars into a plain-language eligibility screener, helping users—from recent SEE graduates to local farmers—instantly discover and apply for the exact benefits they qualify for.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) and `npm` installed on your system.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/theVikingRuler/project-hamro-subidha.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd project-hamro-subidha
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm start
   ```
   Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

5. **Build for production:**
   ```bash
   npm run build
   ```
   Builds the app for production to the `build` folder.
